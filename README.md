
# Task 6: Host a Static Website with GitHub Pages

## 📌 Objective
Deploy a responsive static website using GitHub Pages as part of the Elevate Labs DevOps Internship.

## 🛠️ Technologies Used
- HTML5
- CSS3
- Git
- GitHub
- GitHub Pages

## ✨ Features
- Responsive website layout
- About Me section
- Technical Skills section
- Featured DevOps projects
- Contact and GitHub links
- Custom styling using CSS

## 📂 Project Structure
```text
task6-github/
├── index.html
├── README.md
└── screenshots
```

## 🚀 Deployment Steps
1. Created an `index.html` file containing the website.
2. Initialized a Git repository.
3. Pushed the source code to GitHub.
4. Opened the repository's Settings → Pages.
5. Selected **Deploy from a branch**.
6. Selected the `main` branch and `/(root)` directory.
7. Published the website using GitHub Pages.
